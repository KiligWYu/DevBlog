iCollect V1.3 & iColor V2.0

2018-05-15

今早 iCollect Version 1.3 版本和 iColor Version 2.0 版本一起通过审核，上架 App Store。

iCollect V1.3

更新内容

  • 「花密」移动到了「更多功能」页面
  • 「花密」的小组件增加了 Tapic Engine
  • 「每日一文」的字体换成系统字体，减小 App 体积（之前的版本用的思源宋体）
  • 网络变化的 banner 改为只在断网时显示
  • 首次安装启动显示 Tips
  • 增加了「关于开发者」
  • 去掉了桌面图标的 3D Touch
  • 其他的细节调整和 bug 修改

iColor V2.0

更新内容

  • 全新 UI
  • 去掉了导出为 JSON 文件功能
  • 增加了「关于开发者」
