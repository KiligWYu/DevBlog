favicon.ico

这个图标一般都是放在网站的根目录下的，当打开一个网站时，会显示在浏览器标签页上。

favicon.ico 用途

比如 Alfred 中自定义些搜索，为其添加图标。

如何获取 favicon.ico

http[s]😕/domain/favicon.ico

一般地，大部分网站的这个图标会放在其根目录下，并以 favicon.ico 命名，所以可以直接访问 http[s]://domain/favicon.ico 来获取该图标。如 https://kiligwyu.com/favicon.ico、https://www.google.com/favicon.ico。

公共 API

有些 favicon.ico 图标并不是放在网站根目录的，用上面的方法获取不到，可以用下面的公共 API 来获取。

  • getfavicon: http://www.getfavicon.org/
  • Google: https://www.google.com/s2/favicons?domain=domain，如 https://www.google.com/s2/favicons?domain=youku.com，但是其获取到的图标是 16 x 16 的，并不一定是原始大小

网站源码

可以从网站源码中寻找对 favicon.ico 的声明，进而找到其地址。
